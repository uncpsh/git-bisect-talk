## Skip demo (Speaker C)

`68b080a` has a syntax error, so `test.py` crashes there (exit 1) while the wrapper
reports skip (exit 125):

```
$ git checkout 68b080a
$ python3 test.py; echo "exit $?"      # SyntaxError ... exit 1
$ ./bisect-check.sh; echo "exit $?"    # exit 125 = skip
$ git checkout main
```

Neither demo above lands on `68b080a`, so it never disturbs Demo 1 or Demo 2.
In a real bisect, `git bisect run ./bisect-check.sh` would skip it automatically.
